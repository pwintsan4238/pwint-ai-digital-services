# AI Prompt Vault

Burmese-language prompt library for 2D stickman character & scene designs.

- Viber-number gate popup (free access / free tutorial)
- 4 design cards: photo + video slideshow, character & scene prompts with copy buttons
- 3-part tutorial videos (Part 1 coming soon: add `videos/tutorial-1.mp4`)
- Membership plans + KBZ Pay payment flow (plan -> pay -> check -> order finish -> thank you)

## Edit
Everything is in `index.html`. See the `CONFIG` block near the bottom:
`contactViber`, tutorial video paths, and `leadWebhook` (Google Apps Script URL that saves Viber numbers/orders to a Google Sheet; the script is in the comment above it).

## Files
- `img/` design photos, `videos/` design + tutorial videos (`design-1..4.mp4`, `tutorial-1..3.mp4`)
